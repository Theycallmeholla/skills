## Design Context

### Users
People browsing this public skills repo on GitHub: developers and operators deciding whether a
skill is worth installing, and the owner coming back to remember what a skill does. They read
on github.com, in light or dark theme, often skimming.

### Brand Personality
Collectible and confident, playful but clean: each skill is a trading card in a set of 41.
Clear over clever. Every claim on a card is a fact from the skill's SKILL.md.

### Aesthetic Direction
Trading cards. Warm card stock (#F6F1E7), ink (#1D1A16), a hard offset print shadow, one
category colour per frame (discovery violet, code teal, UX amber, docs green, content magenta,
meta slate). Big Shoulders Display for names and stats, Atkinson Hyperlegible for text.
Cards carry their own background so they read on both GitHub themes.

### Design Principles
1. The card is the TL;DR: name, type line, one ability sentence, four stats.
2. Show the output, not a description of it: a real-format example on every page.
3. Motion only where motion is the point (swipe-deck, secret-shopper, walkthrough-gif).
4. Fictional data, labelled as such. The repo is public.
5. Scannable: labelled rows, short bolded lead-ins, no walls of text.
